One-time Shortcut setup
  1. Add Run JavaScript on Web Page and paste the collector JavaScript from the button below.
  2. Add Copy to Clipboard after it.
  3. Set Copy to Clipboard to copy the JavaScript Result.
  4. When browsing Instagram in Safari, run the Shortcut from the Share Sheet. It only copies data; it does not contact Render.

2. Paste Instagram HTML

For follower/following pages, copy the loaded page HTML from Safari and paste it here. The server extracts Instagram profile links, matches avatar URLs when available, resolves missing avatars, deduplicates them, and queues them for CLIP.

Shortcut for HTML copy
  1. Use Run JavaScript on Web Page.
  2. JavaScript: completion(document.documentElement.outerHTML);
  3. Add Copy to Clipboard and set it to JavaScript Result.
  4. Open the Instagram followers/following page in Safari, scroll until the profiles you want are loaded, run the Shortcut, then return here and paste.

3. Bulk Import

Paste up to 10,000 Instagram usernames or profile URLs. One per line is easiest. You can also paste JSON exported from the scraper. If an avatar URL is included, it goes straight to CLIP; otherwise the server will try to resolve the profile image first.
