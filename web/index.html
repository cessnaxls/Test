iPhone Shortcut Collector

No extension required. In Safari, run your Shortcut on an Instagram page to collect every profile currently loaded in that page and send it to this library.

Setup entirely on iPhone
  1. Tap Copy Shortcut JavaScript above.
  2. Open the Shortcuts app and create a new shortcut named Collect Instagram Profiles.
  3. Open the shortcut details and enable Show in Share Sheet. Set it to receive Safari Web Pages.
  4. Add Run JavaScript on Web Page. Paste the copied JavaScript and set the web page input to Shortcut Input.
  5. Add Get Dictionary from Input.
  6. Add Get Dictionary Value for records, and another for page_url.
  7. Add a Dictionary with: device_id = the Device ID above, records = the records value, page_url = the page_url value, and message = Collected by iOS Shortcut.
  8. Add Get Contents of URL. URL: . Method: POST. Request Body: JSON. Use the Dictionary from the previous step.
  9. Optional: add Show Result after the request so you can see how many profiles Render accepted.

Use: browse instagram.com in Safari, scroll, then Share → Collect Instagram Profiles. Repeat whenever you want to capture the profiles currently loaded. Render deduplicates repeats automatically.
